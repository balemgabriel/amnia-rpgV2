Elfos, Anões, Humanos, Nwiamuh podem ter uma linhagem mista, outras raças só conseguem se misturar entre sua classificação por exemplo Goblins, trolls e orcs todos se encaixam na categoria de Ogroide, portanto podem ter uma linhagem mista.

Algumas Raças tem acesso a fichas de conhecimento e cultura exclusivas.

Durante a criação de personagem você escolhe uma linhagem & ou raça, começando com 3 pontos de ancestralidade nos quais você pode comprar traços positivos e negativos, comprar traços negativos lhe concede pontos de Ancestralidade e são a única maneira de adquirir Pontos de Ancestralidade depois da criação de personagem. Traços que custam 0 são considerados de graça e é recomendado sempre pegar eles quando escolhe uma raça.

# Traços Raciais

( 2 ) - lorem: Usar Ímpeto para re-rolar dados permite re-rolar 1 dado extra.

( 2 ) - lorem; Recebe 2 pontos para distribuir em Fichas de Cultura ou Conhecimento

( 2 ) - lorem; Escolhe um atributo e recebe +1 dado em SAVES desse atributo.

( 1 ) - lorem; Você recebe 1 dado extra para resistir as Portas da Morte.

( 0 ) -  lorem; Você recebe 2 especializações.

# Traços Negativos

( -1 ) - Choque de Fé; Falhar um teste de VON por margem de 4 faz você perder 1 Ímpeto.

( -2 ) - Pesado: Recebe -1 no deslocamento, e -1 dado em testes de atletismo.

( -2 ) - Régua alta: Falhar um teste no qual você é especializado faz você perder 1 Ímpeto.
